# DevSpace | Página de perfil

Página de perfil personal desarrollada como parte del bootcamp de Desarrollo Full Stack de Skillnest.

## Descripción

Este proyecto presenta mi perfil como estudiante de Ingeniería Informática y desarrollador Full Stack en formación. Incluye información personal, enlaces profesionales, proyectos y tecnologías relacionadas con mi aprendizaje.

## Tecnologías utilizadas

- HTML5: estructura y contenido semántico.
- CSS3: estilos, diseño y posicionamiento de elementos.
- Flexbox: organización de componentes.
- Media queries: adaptación a distintos tamaños de pantalla.
- Bootstrap Icons: iconografía de la interfaz.
- Git y GitHub: control de versiones y publicación del proyecto.

## Características

- Diseño adaptable a dispositivos móviles y computadores.
- Tarjeta de perfil con fotografía personal.
- Sección de presentación profesional.
- Panel lateral con información de proyectos y tecnologías.
- Enlaces a GitHub y LinkedIn.
- Efectos visuales e interacciones mediante CSS.

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/ToroFelipe17/devspace-perfil.git
```

2. Abrir la carpeta del proyecto.
3. Ejecutar `index.html` en un navegador web.

No requiere instalaciones ni dependencias adicionales para visualizar la página.
